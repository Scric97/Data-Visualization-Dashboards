🐍 **Python Data Visualization & Interactive Dashboards**

A collection of data analysis and visualization projects developed in Python, showcasing data story-telling, geospatial mapping, and interactive Web Dashboards.

This project is part of the **IBM Data Analyst Professional Certificate** curriculum.

---

🎯 Key Highlights & Modules

1. Data Visualization & Exploratory Analysis
* **Tools:** `matplotlib`, `seaborn`, `folium`
* **Features:** Advanced distribution plots, correlation heatmaps, line charts for trends, and interactive geographic maps showing location-based data.

2. Interactive Web Dashboard (Plotly & Dash)
* **Tools:** `plotly`, `dash`
* **Features:** Built a web-based interactive application allowing users to select parameters via dropdowns/sliders and dynamically update charts in real-time.

3. Financial & Revenue Data Extraction
* **Tools:** `pandas`, `requests`, `BeautifulSoup`
* **Features:** Web scraping historical stock and revenue data, cleaning dataset records, and plotting visual trends over time.

---

🛠️ Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Folium, Plotly, Dash, BeautifulSoup4
* **Environment:** Jupyter Notebook / VS Code
